# Triage labels

The five canonical triage roles; each label string equals its role name.

| Label | Meaning |
| --- | --- |
| `needs-triage` | Unprocessed incoming item |
| `needs-info` | Blocked on more information from the reporter |
| `ready-for-agent` | Triaged and ready for an agent to work |
| `ready-for-human` | Needs a human decision or action |
| `wontfix` | Closed without action |

Repo-specific labels coexist: `packages` marks every issue in this repo.
