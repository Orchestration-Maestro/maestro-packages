# maestro-security: coverage summary

The decomposition campaign supplies the evidence for the unified design.
Its 2,168 qualified entries include 42 correction overlays; each entry has
a design destination. Mapping a capability is not a claim that it is built.

The current graph accounting records 798 two-sided witnesses and 1,913 explicit
missing-side exclusions. One source-identity flag remains open in issue #21;
it is not accepted as proof. Evidence records and qualified capability entries
are different populations, so these totals are not interchangeable.

Before catalog or runner work proceeds, the design review must accept the
capability mapping and each unresolved evidence disposition. Implementation
then follows the build order and behavioral tests in the
[master spec](SPEC.md) and [autonomy spec](AUTONOMY.md).
