# maestro-extensions

Extension packages for [Maestro](https://github.com/Orchestration-Maestro/maestro), built on its extension contract.

| Crate | Description |
|---|---|
| `maestro-prompt-suffix` | Marketplace showcase: hooks the input event and appends an instruction to user prompts. |
| `maestro-security` | Unified security framework: one pipeline, five agents, extension and MCP surfaces. |

Until `maestro-extensions-wasm` is published on crates.io, extension crates depend on it through the maestro repository's `main` branch.
